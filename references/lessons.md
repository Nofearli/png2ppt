# Lessons —— 实战踩坑清单

全部来自真实项目返工。**写 build 脚本前通读一遍；验收对照逐条排查。**

## 素材（修补/裁剪）

1. **标签徽章必须整框修补**。原图里 P1/E1 这类"框+文字"是一体的，只修补文字区域会在框位置留下边框弧线残迹。修补框 = 文字框外扩到边框外沿。
2. **裁剪绝不切断卡片边框、轮廓线、装饰物**。裁剪边落在任何一条可见线条上都会产生硬切边。宁可把裁剪范围加宽把整个装饰包进来，再用 `soft_edge()` 羽化融合。
3. **裁剪图不得超出所在卡片边界**。上缘超出 0.01 英寸都会在渲染里露出来。
4. **被裁图标周边的卡片底色要实测**。采样图标左右/上下的真实像素，若卡片是渐变（如"左蓝右白"），PPT 里的卡片必须用相同端点、相同方向的 `grad_fill()`，否则羽化边缘会出现色差晕。
5. **inpaint 方向选择**：平滑背景上的文字用 `h`（按行左右插值）；贴着轮廓线/边缘的残字用 `v`（按列上下插值），否则插值会把轮廓颜色拖进区域形成条纹。
6. **white_to_alpha 阈值 208/242**：过窄会留白色晕圈，过宽会啃掉图标浅色部分。
7. **修补完必须生成 contact sheet 逐个检查**，再进 S4。带残迹的素材进了 build 就要返工两步。

## Build（python-pptx）

8. **z-order**：跨面板的覆盖元素（标题胶囊条、循环连接线）必须在面板底色之后绘制——即代码里放在最后，否则会被面板底色盖掉半截。
9. **`In()` 参数逐个传**：`In(x), In(y), In(w), In(h)`，不能 `In(x, y, w, h)`。
10. **表格必须剥离自带样式**：`add_grid_table()`（内含 strip）+ 逐格 `cell_borders()`；否则 PowerPoint 默认蓝色带纹样式。
11. **公式上下标**：rich-run `("corr", "sub")`；实现是 run baseline=-25000/30000 + 字号×0.72。同一行内混排用元组列表，跨行用列表的列表。
12. **胶囊条** `radius=0.5`（短边比例上限）；普通卡片 0.05~0.3。
13. **阴影**：`rrect` 会在 spPr 留下空 `effectLst`，`add_shadow` 内部已做复用处理；不要手动 append 第二个 effectLst。
14. **同名对象全图配色必须一致**（如同一个区域在两个面板出现）：建一个 palette key，两处引用同名。

## 验收

15. **必须放大对照**：整体 100% 看不出的问题（残弧、0.01in 超界、接缝），放大 3~5 倍一眼见。逐区域过，不要只看整体。
16. **渲染预览宽度 = 原图 px × 2**，否则文字发虚误判。
17. 验收不通过时**先归因**：是素材问题（回 S3）还是布局问题（回 S4），不要在 build 里用覆盖块糊补。
